# Jabrod

**Creative tools you own. Intelligence you can act on.**

Jabrod is a software company based in India. We build open-source creative software and applied machine learning for businesses.

[Website](https://jabrod.com) · [Microsoft Store](https://apps.microsoft.com/detail/9P0KS6185QSX) · [JBD on GitHub](https://github.com/Jabrod/jbd) · [LinkedIn](https://in.linkedin.com/company/jabrod)

## Jabrod Art

Jabrod Art is our creative suite: video, image, audio and 3D tools in one environment, with a single sign-in and a shared asset library, running on your own computer.

**[JBD](https://github.com/Jabrod/jbd)** is the first Jabrod Art product and is available now: a video editor for Windows 10 and 11 with a multi-track timeline, colour grading, audio mixing, titles, captions and 4K export.

## Jabrod Signals

Jabrod Signals predicts which customers a business is likely to lose, and states the reasons behind each prediction, using that business's own data. It is currently offered through pilot programmes.

- Product page: [jabrod.com/signals](https://jabrod.com/signals)
- Pilot application: [jabrod.com/signals/apply](https://jabrod.com/signals/apply)
